# OAuth Token 与 Agent 调用密钥分离

## 状态

已接受。

## 背景

工作 Agent 既需要代表用户访问配置管理接口，也需要通过兼容 OpenAI 或 Anthropic 的 SDK 高频调用模型代理。OAuth access token 有效期较短且承担登录会话语义，直接把它作为模型和 MCP 的长期调用凭据会混合身份会话与资源调用权限，也无法为不同用途独立撤销权限。

## 决策

OAuth access token 只用于工作 Agent 登录后的管理 API，包括拉取配置和管理调用密钥。模型代理使用用户创建的调用密钥，未来 MCP 代理复用同一种密钥，并分别要求 `model:invoke` 和 `mcp:invoke` 权限。

调用密钥原文只在创建和轮换时返回一次，服务端仅保存 SHA-256 摘要、展示前缀、权限范围和生命周期元数据。用户停用、密钥到期或撤销后，调用立即失效。

## 影响

- 工作 Agent 需要将调用密钥保存到操作系统安全存储。
- 模型和 MCP 调用可以独立于 OAuth 登录会话续期，但仍受用户启停状态约束。
- 模型代理可以直接作为官方 SDK 的自定义 Base URL，并使用调用密钥作为 SDK API Key。
- 新的资源调用入口必须声明并校验所需权限范围。
